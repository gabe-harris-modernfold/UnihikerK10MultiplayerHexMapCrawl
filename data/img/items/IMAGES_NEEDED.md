## Placeholders (present — monochrome amber pixel art, 16px grid @2x)

Generated by hand-drawn 16×16 grids; the `<img onerror>` in `ui-items.js`
swaps a missing `icon_<id>.png` for the item's **category** icon, then the
generic skull if the category is unknown (see `ITEM_ICON_FALLBACK` in
`game-data.js`). Palette is `--gold-hi` / `--txt` only so they sit on the
dark slot background like the rest of the UI.

| File | Purpose |
|------|---------|
| `item_placeholder.png` | Skull, 128 px — missing full illustration |
| `icon_placeholder.png` | Skull, 32 px — generic missing badge |
| `icon_gulpable.png`    | Flask — category 0 Gulpable (consumable) |
| `icon_bolton.png`      | Wrench — category 1 Bolt-On (equipment) |
| `icon_salvage.png`     | Gear — category 2 Salvage (material) |
| `icon_relic.png`       | Key — category 3 Relic (key item) |

Firmware note: every file under `data/img/*/` is loaded into the PSRAM image
cache at boot (`MAX_IMG_CACHE = 100` in the .ino). These six count toward it.

## Naming Convention

- Full illustration: `item_<id>.png`
- Badge icon: `icon_<id>.png`
- Recommended formats: PNG with transparency

## Art Style Notes

Post-apocalyptic wasteland aesthetic — weathered, desaturated, gritty.
Icons should read clearly at 32×32 (simple silhouette, high contrast).
Illustrations can have more detail but should still feel dark/worn.
