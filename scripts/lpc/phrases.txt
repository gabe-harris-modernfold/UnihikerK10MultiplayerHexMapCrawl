# K10 speech vocabulary -> snd-vocab.h (scripts/lpc/gen_vocab.py).
#
#   ID | text
#
# ID becomes the enum VOC_<ID>. Keep IDs stable: firmware refers to them by
# name. Order matters in two places and is load-bearing:
#   * N1..N19, N20..N90 -- sndSayNumber() indexes them arithmetically.
#   * DOOM00..DOOM32    -- DOOM_TAUNTS in data/game-data.js, tier*3 + idx, so
#                          the K10 speaks exactly the line each phone shows.
#   * TC1..TC4, WX0..WX5 -- indexed by threat band / weather phase.
# Lines are lower case on purpose; the TTS reads punctuation as pauses.
